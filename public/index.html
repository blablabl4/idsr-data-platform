Apresentação para Recrutadores e Líderes

Como ler e entender este projeto

1 De onde vêm os dados? (100% Reais e Oficiais)

Nenhum dado é fictício. O projeto compila números reais de duas pesquisas oficiais de referência nacional: a base de CNPJs da Receita Federal / Ministério do Desenvolvimento (MDIC) e o Estudo de Demografia das Empresas (CEMPRE / IBGE), cruzados com as estatísticas do estudo oficial Sobrevivência das Empresas no Brasil (Sebrae/Receita Federal).

2 O que este painel faz na prática?

Ele responde perguntas práticas de negócio: Qual o impacto real do capital inicial na sobrevivência da empresa? Quais regiões possuem maior retenção de negócios? O Simulador Interativo aplica os coeficientes estatísticos comprovados pelo Sebrae e IBGE para calcular a probabilidade de encerramento em até 24 meses.

3 Como avaliar a engenharia e o código?

• Para Recrutadores de Negócios: Veja os gráficos, indicadores e o simulador.
• Para Tech Leads e Engenheiros: Clique em "Ver Arquitetura" ou "Exportar Modelo" em qualquer aba para inspecionar os pipelines em PySpark, modelos dbt com testes de schema, DAGs no Apache Airflow, DDL SQL e a API FastAPI.
